# Phase 3 placeholders

This directory is intentionally minimal in Phase 1/2. Phase 3 fills:

- `components/` — Accessible React components (ARIA, keyboard nav)
- `pages/` — Route-level pages (Landing, Dashboard, Chat, Incidents)
- `hooks/` — `useAuth`, `useChatStream`, `useFirestoreQuery`
- `services/` — Firebase init, typed API client
- `context/` — Auth context, locale context
- `i18n/` — Multilingual message catalogs
- `tests/` — Vitest + @testing-library + axe-core a11y tests
